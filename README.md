# 🎬 MovieExplorer

**MovieExplorer** is a modern, responsive web application built with React and Tailwind CSS that allows users to explore movies and TV shows, search dynamically via the TV Maze API, and view comprehensive details in an interactive modal.

---

## ✨ Features

* **Dynamic Search:** Real-time search functionality that queries the TV Maze API instantly as you type.
* **Interactive Details Modal:** Clicking "See Details" on any movie card opens a gorgeous responsive modal displaying a backdrop banner, poster, ratings, release year, genres, summary, and network information.
* **Responsive Grid Layout:** Fully optimized for all screen sizes, from mobile phones to ultra-wide desktop displays using Tailwind CSS grid and flexbox.
* **Robust State & Error Handling:** Gracefully handles loading states, empty search results, and fetch errors.
* **Client-Side Routing:** Seamless navigation powered by React Router.

---

## 🛠️ Tech Stack

* **React** (v18+)
* **React Router** (v6)
* **Tailwind CSS** (for styling and responsive design)
* **React Icons** (for UI icons)
* **TV Maze API** (External REST API for show data)
